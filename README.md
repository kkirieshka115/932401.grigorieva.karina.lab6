# Лабораторная работа №6. Клиент-серверное приложение и PWA

**Выполнила:** Григорьева Карина, группа 932401  
**Вариант 15:** «Список фильмов с рейтингом» (**MovieList**)

## О проекте
Веб-приложение для просмотра каталога фильмов с фильтрацией по рейтингу, сортировкой по убыванию оценки и поддержкой автономной работы (PWA).

**Стек технологий:** Node.js, Express, HTML5, CSS3, JavaScript (Fetch API), Service Worker, Web App Manifest.

## Структура проекта и назначение файлов
* `server.js` — главный серверный файл (Express, порт `3000`). Хранит данные о фильмах, раздаёт статику из `public/`, обрабатывает API-маршруты, фильтрует, сортирует и проверяет входные параметры.
* `package.json` — паспорт проекта: название, настройки запуска и список зависимостей (`express`).
* `package-lock.json` — фиксирует точные версии установленных библиотек для одинакового запуска на любом компьютере.
* `.gitignore` — список исключений для Git (не пускает папку `node_modules/` в репозиторий GitHub).
* `public/index.html` — главная страница каталога: шапка, форма фильтрации по рейтингу, быстрые кнопки-пресеты, сетка карточек и модальное окно фильма.
* `public/about.html` — страница «О работе»: информация об авторе, индикатор состояния сервера и кликабельные ссылки для проверки чистого JSON.
* `public/app.js` — клиентский JavaScript: регистрирует Service Worker, отправляет `fetch`-запросы к API, отрисовывает карточки фильмов, обрабатывает ошибки и управляет модальным окном.
* `public/style.css` — стили оформления интерфейса, адаптивная сетка (CSS Grid) и оформление модального окна.
* `public/manifest.json` — манифест PWA: задаёт имя приложения, иконку, цвета и режим `standalone` для установки на устройство.
* `public/sw.js` — Service Worker: перехватывает запросы, кэширует HTML, CSS, JS, постеры и ответ `/api/movies` в `Cache Storage` для работы без интернета (офлайн-режим).
* `public/icon.svg` — векторная иконка приложения для вкладки браузера и установки PWA.
* `public/posters/` — папка с локальными изображениями постеров (`1.jpg` – `10.jpg`), которые кэшируются для офлайн-доступа.

## API-маршруты
* `GET /api/movies` — список всех фильмов по убыванию рейтинга.
* `GET /api/movies?minRating=8.5` — фильтрация по минимальному рейтингу (`400 Bad Request` при некорректном значении).
* `GET /api/movies/:id` — получение карточки конкретного фильма по ID (`404 Not Found`, если не найден).
* `GET /api/status` — проверка статуса и времени работы сервера.

## Запуск проекта
1. Установить зависимости: `npm install`
2. Запустить сервер: `node server.js`
3. Открыть в браузере: `http://localhost:3000`
